# 🎧 Mood-Based Music Recommender (Java Console App)

A **unique Java console project** that recommends songs based on your current mood (happy, sad, romantic, energetic, etc.).

## 🚀 Features
- Add new songs with mood tags  
- View all saved songs  
- Get recommendations for a specific mood  
- Stores songs permanently in a text file  

## 🧠 Concepts Used
- Object-Oriented Programming  
- Java Collections (ArrayList)  
- File Handling (I/O Streams)  
- Conditionals and Loops  

## 🖥️ How to Run
```bash
javac *.java
java Main
